LIFE_OS Calendar Integration

LIFE_OS is a personal automation system. Its Google Calendar integration is used to read calendar information for private daily briefings and to perform calendar actions only when the user explicitly requests them.

The integration is intended for the owner's personal use, not as a public consumer application.

Google user data

Calendar data is used only to provide requested LIFE_OS functions. It is not sold, used for advertising, or made publicly available.
